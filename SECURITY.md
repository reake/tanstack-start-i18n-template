# Security Policy

## Scope

The supported security surface is the latest commit on the `main` branch. This
repository is a starter template, so deployments may add infrastructure that is
outside this scope.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private Security Advisories for the repository, including reproduction steps,
affected files or versions, and the impact you observed.

We will acknowledge reports as soon as practical and coordinate a fix or mitigation
before public disclosure.
